# Cricut SVG production utility

Sign in through the existing staff login and select **Cricut SVG Generator** from the staff sidebar. The tool is at `/cricut_svg` inside the staff portal layout. Opening `/staff-login` on its own still takes staff to `/sales/create`; opening `/cricut_svg` while signed out returns there after sign-in. This route is independent of the customer vinyl ordering flow.

1. Use the existing Canva Pro connection and the eight-page `CANVA_VINYL_DESIGN_ID` template. Each PF font maps to its corresponding page, with the `VINYL_TEXT` autofill field. The font files are not needed locally.
2. Enter one line of text, its font, final visible ink width in cm, and a quantity for each content row.
3. Set the separation in mm and optionally permit quarter-turn rotation. Generate mats, inspect them, and download each SVG or a ZIP of all SVGs.

The generator autofills Canva for each distinct text and font, exports only that font page as a PDF, converts the embedded vector glyphs into outline paths, and rejects any raster images or unsupported effects. Identical text/font pairs are cached for the browser session. Canva creates a filled design for each distinct text/font pair; repeated Optimize Again operations reuse the outlines already fetched on this page.

The vinyl mat is 110 × 160 mm. For Cricut Joy cutting on a mat, the actual cuttable area is 107.95 × 158.75 mm, so the packer keeps every path within that smaller area. The exported SVG canvas is tightly cropped to the occupied artwork; Design Space therefore imports the real cut image size instead of a blank 110 × 160 mm page. SVG physical width and height are expressed in inches (millimetres divided by 25.4) because Design Space imported a 50 mm numeric width as 127 cm. The viewBox and all path coordinates remain in millimetres. Cropping shifts all cuts together and preserves their exact physical sizes and relative placement. Only filled glyph outlines are exported, ordered by original content entry; all placement, rotation and scaling are baked into their path coordinates, with no nested SVG transforms. The preview background and mat border are not cut paths. If a design cannot fit either orientation at its requested size, generation stops with an error. Import SVGs into Cricut Design Space at their original dimensions, keep the layout together (Attach if Design Space separates it before cutting), select On Mat, and verify physical dimensions before cutting.

The packer tries several sorted and shuffled global layouts with MaxRects free-space splitting, so smaller designs can fill rectangular gaps and contents can migrate between mats on another pass. It favors fewer mats and a compact occupied footprint. This is a heuristic: it does not mathematically guarantee the optimum or nest inside concave letter shapes. Utilization and waste use design bounding rectangles as estimates, rather than true path area. Safe spacing is applied to the bounding boxes and half the configured separation is kept from the mat edges.

Implementation: `app/cricut_svg/`, `app/api/cricut-svg/outlines/`, the existing Canva OAuth helper, and a vector PDF transcoder. No customer flow files were changed. The Canva PDF conversion should be verified with each PF page before production cutting; non-vector exports are rejected automatically.
